# RBEI — RecipeBookEnoughItems

**Un livre de recettes vanilla-friendly pour Fabric.**  
Remplace le recipe book de Minecraft : objets, recettes, craft, butins, potions, minerais… sans quitter ta partie, et sans JEI/REI/EMI.

**Minecraft 26.2** · **Fabric** · **client uniquement**.

---

## Pourquoi RBEI ?

Le livre de recettes vanilla est limité. **RBEI** garde un feeling vanilla tout en offrant un navigateur style JEI qui indexe :

- Crafts & fours  
- Étapes de potions  
- Butins / drops de mobs (avec % si dispo)  
- Plages Y des minerais  
- Beaucoup de recettes de mods (auto-détection)  

Pas besoin de JEI / REI / EMI.

---

## Fonctionnalités

### Navigateur
- Liste d’objets + recherche (`@mod`, `#tag`)  
- Catégories, favoris (Nether Star), barre Recent  

### Recettes & usages
- Clic gauche / **R** = recettes · clic droit / **U** = usages  
- Transfert **+** vers établi / four  
- Favoris ☆ / ★ (pas confondu avec le transfert)  

### QoL
- Options (**O**), thème (**T**), overlay craftable, copie d’ID (**C**), comparaison (**=**)  
- Remplace le bouton du livre de recettes vanilla

## Contrôles

| Entrée | Action |
|--------|--------|
| **O** | Ouvrir RBEI / options |
| Gauche / **R** | Recettes |
| Droit / **U** | Usages |
| Molette | Favori |
| **C** | Copier l’ID |
| **T** | Thème |
| **+** | Transfert |
| **=** | Comparer |
| Backspace | Retour |
