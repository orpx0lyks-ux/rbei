# FAQ

## Is this JEI / REI / EMI?

No. Same idea (browse items & recipes), different mod. You do **not** need those installed.

## Does the server need RBEI?

No. **Client-only.**

## Does transfer work everywhere?

**+** works when you opened RBEI from a crafting table or furnace with a compatible grid. Shift fills as many crafts as possible.

## Where are favorites stored?

Locally in `config/rbei-client.json`.

## Incomplete recipes?

Some custom machine UIs may show incomplete layouts. Brewing, loot, and ores have dedicated sources.
