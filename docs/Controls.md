# Controls

| Input | Action |
|-------|--------|
| Open key (default **O**) | Open / close RBEI |
| Left click / **R** | Show recipes |
| Right click / **U** | Show uses |
| Middle click | Toggle favorite |
| **C** | Copy hovered item ID |
| **O** (inside RBEI) | Options panel |
| **T** | Toggle theme |
| **+** | Transfer ingredients to crafting table / furnace |
| **=** | Add item to compare |
| Backspace | Go back |

## Tips

- Favorites use **☆ / ★** (not confused with transfer **+**)  
- Favorites tab uses the **Nether Star** icon  
- Search supports `@mod` (namespace) and `#tag`  
- Transfer works when RBEI was opened from a crafting table or furnace screen
