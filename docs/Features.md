# Features

## Vanilla-friendly recipe book

RBEI replaces the vanilla recipe book button on inventory, crafting table, and furnaces with a JEI-style browser — while keeping a clean, vanilla feel.

## What it indexes

- Crafting & smelting  
- Brewing steps  
- Loot / mob drops (with chances when available)  
- Ore generation (Y range / best layer)  
- Many mod recipes (auto-detected)

## QoL

- Favorites & recent items  
- Craftable overlay  
- Options: dark theme, UI sounds, export JSON  
- Item compare  
- Copy registry IDs
