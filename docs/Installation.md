# Installation

## Requirements

| | |
|--|--|
| Minecraft | **26.2** |
| Loader | Fabric Loader ≥ 0.19.5 |
| API | [Fabric API](https://modrinth.com/mod/fabric-api) |
| Java | **25+** |

## Steps

1. Install Fabric Loader for Minecraft 26.2  
2. Install Fabric API  
3. Download `rbei-<version>.jar` from [Modrinth](https://modrinth.com/mod/rbei)  
4. Put the jar in your `.minecraft/mods` folder  
5. Launch the game and open RBEI with **O** (default keybind)

## Config

Optional client config: `config/rbei-client.json`  
(theme, sounds, craftable overlay, favorites, recent)

RBEI is **client-only** — the server does not need the mod.
