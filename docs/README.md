# RBEI Wiki

**RBEI (RecipeBookEnoughItems)** is a vanilla-friendly JEI-style recipe book for Fabric.

It **replaces Minecraft’s recipe book** with a clean item & recipe browser — crafts, uses, brewing, loot, and ores — without installing JEI, REI, or EMI.
