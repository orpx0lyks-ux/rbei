# RBEI — RecipeBookEnoughItems

A vanilla-friendly recipe book for Fabric.  
Replaces Minecraft’s recipe book with a JEI-style item & recipe browser.

**Minecraft 26.2** · Fabric · client-only

## What it does

- Browse items (search, categories, favorites, recent)
- View recipes & uses (crafting, smelting, brewing, loot, ores)
- Transfer ingredients to a crafting table or furnace with **+**

## Controls

| | |
|--|--|
| **O** | Open RBEI / options |
| Left / **R** | Recipes |
| Right / **U** | Uses |
| Middle click | Favorite |
| **+** | Transfer to grid |

## Requires

[Fabric API](https://modrinth.com/mod/fabric-api) · Java 25+
